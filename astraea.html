HOSTING & LOCAL SETUP GUIDE

This game is fully contained inside a single self-contained HTML file using HTML5 Canvas & Web Audio API. You can launch or host it using any of the following methods:

# Method 1: Direct File Launch
Double-click index.html in any modern web browser.

# Method 2: Python Local HTTP Server
python -m http.server 8000 -> Visit http://localhost:8000

# Method 3: Node.js http-server
npx http-server .

# Method 4: Deployment
Push to GitHub & enable GitHub Pages under repository settings.
